# Treino de Vendas — Marketplace

Marketplace de plugins de treino de vendas para times de planos de saúde.

## Como sua equipe instala (uma vez só)

No Claude (desktop), adicione este marketplace e instale o plugin:

```
/plugin marketplace add SEU-USUARIO-GITHUB/treino-vendas-marketplace
/plugin install treino-vendas-plano-saude@treino-vendas-w3g
```

> Troque `SEU-USUARIO-GITHUB` pelo seu usuário do GitHub e `treino-vendas-marketplace` pelo nome do repositório, caso use outro.

## Atualizações

Quando você atualizar o plugin neste repositório (subir uma versão nova), quem já instalou recebe a atualização ao atualizar o marketplace — não precisa reenviar arquivo pra ninguém.
